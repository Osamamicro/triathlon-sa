Content Dashboardلوحة إدارة المحتوى

The proposal asks for a website staff can run "from the dashboard, never the code." This is that back office — add, edit and remove events, statistics, documents, rules and clubs, and every change appears across the public site. Changes are stored in this browser only (demo). يطلب المقترح موقعاً يديره الموظفون «من لوحة التحكم لا من الشيفرة». هذه هي تلك اللوحة — أضِف وعدّل واحذف الفعاليات والإحصائيات والمستندات واللوائح والأندية، وتظهر كل التغييرات في الموقع العام. تُحفظ التغييرات في هذا المتصفح فقط (تجريبي).

Settingsالإعدادات

This dashboard is a front-end demo. All edits and registrations are stored only in this browser (localStorage) and are never sent anywhere.هذه اللوحة نموذج واجهة أمامية. كل التعديلات والتسجيلات تُحفظ في هذا المتصفح فقط ولا تُرسل إلى أي جهة.

In productionفي النسخة النهائية

  • This front end connects to a headless CMS / dashboard API and a database.تتصل هذه الواجهة بنظام إدارة محتوى ولوحة تحكم وقاعدة بيانات.
  • Staff sign in with roles and permissions; every change is logged.يسجّل الموظفون الدخول بأدوار وصلاحيات، وتُسجَّل كل التغييرات.
  • Documents and event photos are uploaded and stored on the server.تُرفع المستندات وصور الفعاليات وتُخزَّن على الخادم.
