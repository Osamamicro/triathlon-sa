# Task 4.1 — CRM domain, licence issuing, exports, contacts and email blasts (step-level plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole membership desk behind the screens: the CRM tables (athlete with an encrypted national ID, contacts with notes, email blasts with per-recipient rows, a per-year licence counter) with both migration sets; licence numbers `KSA-TRI-{yyyy}-{seq:00000}` that stay unique when ten approvals land at once on either provider; approve/reject with a bilingual mail carrying a PDF licence card; athlete search that works in Arabic on both providers; an Excel export of the whole filtered set with Arabic intact; contacts with notes; and an email blast to a filtered audience that goes out in batches of 100 a minute, skips anyone who opted out, survives a crash, and carries a one-click unsubscribe that only ever fires on a POST. No PII ever becomes a Hangfire job argument.

**Architecture:** Athlete stays one aggregate with one service — the existing `CrmService` gains a partial (`CrmService.Athletes.cs`) the way `EventsService` gained `EventsService.Write.cs`; `Contact` and `EmailBlast` are their own aggregates and get their own services. Every dashboard mutation is still one unit of work: mutate tracked entities, then `ContentCommit.ApplyAsync(...)` (single `SaveChangesAsync` through `IActivityLogger`, then tag eviction — most CRM writes evict nothing and pass `[]`). The two deliberate exceptions are documented in Decisions 1 and 8: `LicenceNumbers` commits a counter in a scope of its own, and `EmailBlastJob` saves once per recipient because it is a batch job, not an editor save. Mail is composed *inside* a Hangfire job from an id, never handed to Hangfire as a message. PDF is QuestPDF (already referenced); Excel is ClosedXML (added here).

**Tech Stack:** ASP.NET Core 10, EF Core 10 (PostgreSQL + SQL Server migration pairs), ASP.NET Core Data Protection (`IDataProtector`), QuestPDF 2026.8.0 (already in `Triathlon.Web.csproj`), ClosedXML 0.105.1 (new), Hangfire 1.8.25, MailKit 4.17, HtmlSanitizer 9.2.1039, xUnit + Testcontainers.

**Spec:** `docs/superpowers/plans/2026-09-06-triathlon-platform-ultra-plan.md` Task 4.1 (lines 76-88, 200-215) and the Week 5 gate; `docs/superpowers/specs/2026-09-06-triathlon-platform-design.md` §2 (roles), §6.2 (`Crm` domain), §6.3 and §7 (athlete registration and event entry flows), §6.4 (PDPL); `docs/HANDOVER.md` §8 "Week 5 — CRM + admin" and §9 Week 5 carry-overs; `docs/qa/2026-09-08-week4-dashboard.md` (F7-F14); `docs/superpowers/plans/2026-09-08-task-3.1-dashboard-foundations.md` (Decisions 1-19, service and commit contracts).

## Decisions recorded by this plan (read before coding)

1. **The licence sequence lives outside the caller's unit of work, in a scope of its own.** A table `LicenceCounters(Year int primary key, Next int)` holds the next unissued sequence for a year. `LicenceNumbers` takes an `IServiceScopeFactory`, not an `AppDbContext`: every attempt opens a fresh scope with its own `AppDbContext`, exactly as `DashboardScope` does for a save. That is the whole point — `CrmService` has the approving `Athlete` tracked on the request's context, and a counter insert that lost a race must be discarded without touching it. **There is no `ChangeTracker.Clear()` anywhere in this codebase**: a discarded attempt discards its whole context with the scope. The claim is a compare-and-swap that is plain SQL on both providers:
   `db.LicenceCounters.Where(c => c.Year == year && c.Next == taken).ExecuteUpdateAsync(s => s.SetProperty(c => c.Next, taken + 1), ct)`.
   `affected == 1` means this caller owns `taken`; `affected == 0` means someone else got there first, so the loop retries. The first approval of a year inserts the row and races on the primary key; a `DbUpdateException` is caught and the loop retries in a new scope. Bounded at `MaxAttempts = 5`; exhausting it throws `ContentValidationException("Id", "Validation_LicenceRetry")`, so the officer reads "try again" instead of a 500. The backstop is a **unique index on `Athlete.LicenceNumber`**, declared without a filter in `AthleteConfiguration` and given a provider-specific filter in each derived context (`"\"LicenceNumber\" IS NOT NULL"` for Npgsql, `"[LicenceNumber] IS NOT NULL"` for SQL Server — SQL Server treats NULLs as equal in a unique index, PostgreSQL does not, so the filter is required on one and harmless on the other). An approval that fails after a successful claim leaves a **gap**. Gaps in a licence register are harmless; two athletes holding one number is not.
2. **PDF library: QuestPDF 2026.8.0** — already referenced in `src/Triathlon.Web/Triathlon.Web.csproj` and already named in spec §7. No second PDF library. The Community licence is free below USD 1 M annual revenue, which the Federation is; `QuestPDF.Settings.License = LicenseType.Community;` is set in `LicenceCardPdf`'s static constructor so the class renders inside a unit test without `Program`. Arabic needs a font with Arabic glyphs and SkiaSharp reads TTF/OTF, so the site's `wwwroot/fonts/*.woff2` cannot be reused: `wwwroot/fonts/Tajawal-Regular.ttf` and `wwwroot/fonts/Tajawal-Bold.ttf` are added as `EmbeddedResource` beside `wwwroot/fonts/Tajawal-OFL.txt` (the SIL Open Font License text, which the licence requires we ship), and registered once with `FontManager.RegisterFontFromEmbeddedResource`. Linux hosts additionally need the `libfontconfig1` package; that is a Week 6 deploy note, recorded in the handover by 4.2.H.
3. **Excel library: ClosedXML 0.105.1** (MIT). Nothing else in the project writes spreadsheets. XLSX is a UTF-8 XML package by construction, so "Arabic intact" is proved by writing an Arabic string and reading the saved bytes back through ClosedXML, plus `worksheet.RightToLeft = true` when the export is taken in Arabic. Exports are served by a minimal-API endpoint under `Policies.Crm` (`/dashboard/exports/...`) rather than JS interop, so they are testable with an `HttpClient` and never push a base64 blob through the circuit. **The export enumerates the whole filtered set**: `CrmService.ExportAsync(filter, ct)` runs the same query builder as `SearchAsync` with no `Skip`/`Take`, and `EventsService.RegistrationsAsync` is unpaged by construction. There is no truncation and therefore no "first 100 rows" hint string.
4. **Unsubscribing is a POST, and the link in the mail is a confirmation page.** An unsubscribe that fires on GET is triggered by every corporate link scanner that pre-fetches URLs, which silently opts people out. So: the visible footer link goes to a public Razor page `/{culture}/unsubscribe?t=...` that renders one "Yes, stop emailing me" button; that button POSTs to `/api/unsubscribe?t=...`, a token-bound, antiforgery-exempt, rate-limited minimal-API endpoint. `EmailBlastJob.Compose` additionally emits RFC 8058 headers `List-Unsubscribe: <https://.../api/unsubscribe?t=...>` and `List-Unsubscribe-Post: List-Unsubscribe=One-Click`, so a mail client's own unsubscribe button posts to the same endpoint. The token is derived, not stored: `IDataProtector` purpose `crm.unsubscribe` over `"{kind}:{id:N}"`. The output is base64url and drops straight into a URL; no column, no index, no expiry (an unsubscribe link must work forever), and rotating the key ring is the revocation mechanism. `"unsubscribe"` joins `PublicSite.ReservedSlugs`.
5. **National ID at rest.** `Athlete.NationalId` is stored through a `ValueConverter` built on `IDataProtector` with purpose `crm.nationalId`. The protector is reached in `AppDbContext.OnModelCreating` from `this.GetService<IDbContextOptions>().FindExtension<CoreOptionsExtension>()?.ApplicationServiceProvider`, so no static state and no constructor change. When that is null the ephemeral fallback is taken **only if `EF.IsDesignTime`** — `dotnet ef` news the context up with options alone and never reads a value — and otherwise throws, so a mis-wired host fails at startup instead of quietly writing ciphertext nobody can read back. A value that will not decrypt (a rotated-away key ring) reads back as the sentinel `"[unreadable]"` rather than throwing, so one bad row cannot take down the athletes list. `Program.cs` calls `AddDataProtection().SetApplicationName("triathlon-sa")` and, when `DataProtection:KeysDirectory` is set, `PersistKeysToFileSystem`. **Deployment note (carried to Week 6):** setting the application name changes the purpose chain, so every existing dashboard cookie is invalidated once on first deploy and staff sign in again; and `DataProtection:KeysDirectory` must point at a backed-up folder outside the deployment directory or a redeploy makes every stored national ID unreadable. The column is 512 characters, never indexed and never searched.
6. **PDPL delete-on-request** is `CrmService.EraseAsync(id, ct)`: it overwrites `FullName`, `Email`, `Phone`, `NationalId`, `EmergencyName`, `EmergencyPhone` and `CityKey` with redaction markers or nulls, sets `ErasedAt` and `EmailOptOut`, and keeps `LicenceNumber`, `Status`, `Category` and the licence dates (the register is a legitimate record). It logs an activity row whose before and after are both `new { Erased = true }` — no snapshot, so no PII reaches the audit trail. An erased athlete is excluded from every blast audience and cannot be approved.
7. **No PII in Hangfire arguments.** `EmailJob.SendAsync(EmailMessage)` is retired and the class deleted; its one caller (`CrmService.ApplyAsync`) enqueues `AthleteMailJob.SendConfirmationAsync(athleteId)`. `AthleteMailJob` also owns `SendLicenceAsync(athleteId)` (which renders the PDF inside the job, so the card never sits in job storage either) and `SendRejectionAsync(athleteId)`. Blasts enqueue `EmailBlastJob.RunAsync(blastId)`. Job arguments are ids and nothing else.
8. **Blast mechanics are crash- and concurrency-safe.** `EmailBlastService.SendAsync` materialises the audience into `EmailBlastRecipient` rows at send time (skipping opt-outs, erased rows and blanks), then enqueues `EmailBlastJob.RunAsync(blastId)`. `RunAsync` carries `[DisableConcurrentExecution(timeoutInSeconds: 600)]` so a Hangfire retry cannot overlap the run it is retrying. It takes the next 100 `Pending` recipients **ordered by `CreatedAt, Id`** — a stable, provider-neutral pair that reads as "in the order they were queued" — and for each one sends and then **saves immediately**: one `SaveChangesAsync` per recipient. That is a deliberate exception to the one-save-per-unit-of-work rule, which is about editor saves; a batch job that saved once at the end would re-send the whole batch after a crash. A code comment says exactly that. If any `Pending` remain the job schedules itself one minute later. A recipient who opted out between materialisation and sending is re-checked and marked `Skipped`.
9. **Clubs stay in `ContentService`, and the Clubs screen stays in the Content group.** The ultra-plan lists a `ClubsService`; `ContentService` already owns `ClubsForEditAsync(bool deletedOnly, CancellationToken ct)`, `SaveClubAsync`, `DeleteClubAsync`, `RestoreClubAsync` and the `CacheTags.Clubs` eviction (clubs render on the public join and training pages, so they are content). Splitting them would move the eviction away from the save, and putting the screen under CRM would put a `Policies.Content` service behind a `Policies.Crm` page. The CRM navigation group is therefore Athletes · Registrations · Contacts · Email; Clubs sits under Content (Task 4.2.B).
10. **Athlete keeps one service.** The ultra-plan's `AthletesService` becomes `CrmService.Athletes.cs`, a partial of the existing `CrmService`, mirroring `EventsService` / `EventsService.Write.cs`. One aggregate, one service. `Contact` and `EmailBlast` are separate aggregates and get `ContactsService` and `EmailBlastService`.
11. **Validation reports every bad field at once.** `ContentValidationException` gains `IReadOnlyList<ContentValidationError> Errors`; the existing single-field constructor produces a one-element list, so no Week 4 caller changes. New CRM saves collect with `ContentErrors` and throw once. `EditShell.Handle` (Task 4.2.A) loops over `Errors`. Retrofitting the Week 4 services to the collector is a Week 6 clean-up.
12. **`ContentGuard` stays scoped.** `Ganss.Xss.HtmlSanitizer` does not document thread safety, and constructing one per request costs microseconds against a request that is already hitting the database. What *is* fixed here is the real defect inside the same finding: a sanitised `<a target="_blank">` now always carries `rel="noopener noreferrer"`.
13. **Event registrations are read, re-statused and exported, never edited in bulk.** `EventsService` gains `RegistrationsAsync`, `AllRegistrationsAsync` and `SetRegistrationStatusAsync`. There is no delete: a cancelled entry is `RegistrationStatus.Cancelled`, which keeps the count honest and the export complete. A status change is audited through `ContentCommit.ApplyAsync("EventRegistration", ...)` with `Audit.Snapshot` on both sides and evicts `CacheTags.Event(slug)`, because the public event page prints the entry count.
14. **Uploaded files keep a recognisable name.** `LocalFileStore` names the stored file `{slug-of-original-stem}-{8 hex}.{ext}` instead of `{guid}.{ext}`, so a document downloaded straight from `/docs/...` or `/media/...` saves under a name a human recognises. The slug is ASCII `[a-z0-9-]`, at most 40 characters, `file` when nothing survives. Eight hex characters is 32 bits, which is not collision-proof and does not need to be: the file is opened with `FileMode.CreateNew`, so a collision throws instead of overwriting and the upload is refused rather than silently replacing someone else's file.
15. **Arabic search is normalised, on both providers.** `a.FullName.ToLower().Contains(term)` translates on both, but PostgreSQL compares case- and diacritic-sensitively while SQL Server usually does not, and neither treats `أحمد` and `احمد` as the same word — which is how people actually type Arabic. So `SearchNormalizer.Normalize` lower-cases, strips tashkeel (U+064B-U+0652 and U+0670), strips tatweel (U+0640), unifies the alef forms (`أإآٱ` to `ا`), maps `ى` to `ي` and `ة` to `ه`, and collapses whitespace. Its output is stored in a `SearchName` column on `Athlete` and `Contact`, maintained by `StampInterceptor` through a new `ISearchable` interface so a row written by any path (service, seed, test) gets one; the query normalises the search term the same way and does a plain `Contains`. No `ToLower()` in SQL, no collation setting, no provider-specific function.
16. **`DateOnly` for the licence dates.** `LicenceIssuedOn` and `LicenceExpiresOn` are `DateOnly`, like the existing `Athlete.DateOfBirth`, which both providers already map to `date`. A licence has no time of day.

```csharp
using System.Text;

namespace Triathlon.Web.Services;

/// <summary>
/// Reduces a name to the one form both the stored search column and a typed search term are compared
/// in. Arabic is written several ways for the same word — hamza on or off the alef, tashkeel present
/// or absent, a stretched tatweel, ة or ه at the end — and neither PostgreSQL nor SQL Server treats
/// those as equal out of the box. Normalising both sides in C# gives one behaviour on both providers
/// with no collation to configure and no provider-specific SQL function.
/// </summary>
public static class SearchNormalizer
{
    /// <summary>Matches the SearchName column width on Athlete and Contact.</summary>
    public const int MaxLength = 512;

    public static string Normalize(string? text)
    {
        if (string.IsNullOrWhiteSpace(text))
        {
            return "";
        }

        var builder = new StringBuilder(text.Length);
        var lastWasSpace = true;   // true so a leading run of spaces is dropped

        foreach (var raw in text.ToLowerInvariant())
        {
            var c = raw switch
            {
                'أ' or 'إ' or 'آ' or 'ٱ' => 'ا',
                'ى' => 'ي',
                'ة' => 'ه',
                _ => raw,
            };

            // Tashkeel (fathatan..sukun), the superscript alef, and tatweel carry no lexical weight.
            if (c is >= 'ً' and <= 'ْ' or 'ٰ' or 'ـ')
            {
                continue;
            }

            if (char.IsWhiteSpace(c))
            {
                if (!lastWasSpace)
                {
                    builder.Append(' ');
                    lastWasSpace = true;
                }

                continue;
            }

            builder.Append(c);
            lastWasSpace = false;
        }

        // TrimEnd rather than Trim: a leading space can no longer exist by construction.
        var result = builder.ToString().TrimEnd();

        return result.Length <= MaxLength ? result : result[..MaxLength];
    }
}
```

```csharp
using Microsoft.AspNetCore.DataProtection;
using Microsoft.EntityFrameworkCore;

namespace Triathlon.Web.Data.Crm;

/// <summary>
/// The data-protection purposes this application uses, and the one fallback the EF design-time
/// tooling is allowed. <c>dotnet ef</c> constructs the context from a <c>DbContextOptions</c> alone,
/// with no application service provider behind it, so the value converter still needs *a* protector
/// to build the model with — it never reads or writes a value there, so an ephemeral key ring is
/// correct. Anywhere else, a missing provider is a wiring bug and must fail loudly: silently
/// protecting with a throwaway key would write ciphertext nobody could ever read back.
/// </summary>
public static class CrmProtection
{
    public const string NationalIdPurpose = "crm.nationalId";
    public const string UnsubscribePurpose = "crm.unsubscribe";
    public const string PreviewPurpose = "content.preview";

    public static IDataProtector NationalId(IServiceProvider? applicationServices)
    {
        var provider = applicationServices?.GetService<IDataProtectionProvider>();
        if (provider is not null)
        {
            return provider.CreateProtector(NationalIdPurpose);
        }

        if (EF.IsDesignTime)
        {
            return DataProtectionProvider
                .Create(new DirectoryInfo(Path.Combine(Path.GetTempPath(), "stf-design-time-keys")))
                .CreateProtector(NationalIdPurpose);
        }

        throw new InvalidOperationException(
            "The application service provider is not reachable from the DbContext, so the national "
            + "identity number could not be protected. Register the context with AddDbContext (which "
            + "sets ApplicationServiceProvider) and call AddDataProtection() in Program.cs.");
    }
```

```csharp
using System.Security.Cryptography;
using Microsoft.AspNetCore.DataProtection;
using Microsoft.EntityFrameworkCore.Storage.ValueConversion;

namespace Triathlon.Web.Data.Crm;

/// <summary>
/// Encrypts a nullable string on the way into the column and decrypts it on the way out.
/// <para>
/// A value the current key ring cannot open reads back as <see cref="Unreadable"/> rather than
/// throwing: that happens when a deployment loses <c>DataProtection:KeysDirectory</c>, and one
/// orphaned row must not take the whole athletes list down with it. The officer sees that the field
/// is unrecoverable, which is the truth, and can ask the athlete for the number again.
/// </para>
/// </summary>
public sealed class ProtectedStringConverter(IDataProtector protector)
    : ValueConverter<string?, string?>(
        plain => plain == null ? null : protector.Protect(plain),
        stored => Read(protector, stored))
{
    public const string Unreadable = "[unreadable]";

    private static string? Read(IDataProtector protector, string? stored)
    {
        if (stored is null)
        {
            return null;
        }

        try
        {
            return protector.Unprotect(stored);
        }
        catch (CryptographicException)
        {
            return Unreadable;
        }
        catch (FormatException)
        {
            // Not even base64url — a hand-edited column, or a value written before the converter.
            return Unreadable;
        }
    }
}
```

```csharp
namespace Triathlon.Web.Services;

/// <summary>One refused field: where it is, what to say, and the format values to say it with.</summary>
public sealed record ContentValidationError(string Field, string Key, IReadOnlyList<object> Arguments);

/// <summary>
/// A dashboard save was refused. <see cref="Errors"/> carries every field the save objected to, so a
/// form can mark all of them at once instead of revealing them one reload at a time;
/// <see cref="Field"/>, <see cref="Key"/> and <see cref="Arguments"/> are the first of them, kept so
/// every Week 4 caller and test compiles unchanged. <see cref="Exception.Message"/> is the English
/// fallback for logs.
/// </summary>
public sealed class ContentValidationException : Exception
{
    public ContentValidationException(string field, string key, params object[] arguments)
        : this([new ContentValidationError(field, key, arguments)])
    {
    }

    public ContentValidationException(IReadOnlyList<ContentValidationError> errors)
        : base(Describe(errors))
    {
        Errors = errors;
        Field = errors[0].Field;
        Key = errors[0].Key;
        Arguments = errors[0].Arguments;
    }

    /// <summary>Every field this one save refused, in the order they were collected.</summary>
    public IReadOnlyList<ContentValidationError> Errors { get; }

    public string Field { get; }

    /// <summary>A key in <c>Resources/DashboardStrings.*.resx</c>, prefixed <c>Validation_</c>.</summary>
    public string Key { get; }

    public IReadOnlyList<object> Arguments { get; }

    private static string Describe(IReadOnlyList<ContentValidationError> errors)
    {
        ArgumentNullException.ThrowIfNull(errors);
        if (errors.Count == 0)
        {
            throw new ArgumentException("A refusal needs at least one error.", nameof(errors));
        }

        return string.Join("; ", errors.Select(e =>
            e.Key + (e.Arguments.Count == 0 ? "" : " (" + string.Join(", ", e.Arguments) + ")")));
    }
}
```

```csharp
/// <summary>
/// Collects every refusal in one save so the form marks all the bad fields at once instead of
/// revealing them one reload at a time. The Week 4 services still throw on the first problem; the
/// CRM saves written in Week 5 use this, and the retrofit of the older services is a Week 6 job.
/// </summary>
public sealed class ContentErrors
{
    private readonly List<ContentValidationError> _errors = [];

    public bool Any => _errors.Count > 0;

    public void Add(string field, string key, params object[] arguments) =>
        _errors.Add(new ContentValidationError(field, key, arguments));

    public void Require(string field, string? value)
    {
        if (string.IsNullOrWhiteSpace(value))
        {
            Add(field, "Validation_Required");
        }
    }

    /// <summary>Bilingual pair rule: both sides or neither, never one.</summary>
    public void RequireBoth(string field, string? en, string? ar)
    {
        if (string.IsNullOrWhiteSpace(en) || string.IsNullOrWhiteSpace(ar))
        {
            Add(field, "Validation_LabelBothLanguages");
        }
    }

    public void MaxLength(string field, string? value, int max)
    {
        if (value is not null && value.Length > max)
        {
            Add(field, "Validation_MaxLength", max);
        }
    }

    public void ThrowIfAny()
    {
        if (Any)
        {
            throw new ContentValidationException(_errors);
        }
    }
}
```

```csharp
    /// rather than silently overwriting somebody else's file.
    /// </summary>
    private static string StoredStem(string originalFileName)
    {
        var stem = Path.GetFileNameWithoutExtension(originalFileName).ToLowerInvariant();
        var slug = NotSlug.Replace(stem, "-").Trim('-');
        if (slug.Length > 40)
        {
            slug = slug[..40].TrimEnd('-');
        }

        if (slug.Length == 0)
        {
            slug = "file";
        }

        return slug + "-" + Guid.NewGuid().ToString("N")[..8];
    }
```
Also update the class summary, which currently claims the stored name is "a fresh GUID": it is now a slug of the original stem plus eight hex characters, and the extension still comes from the sniffed bytes, so a caller still cannot choose a path or an extension. `ImageVariants.WriteAsync(fullPath, directory, id, ct)` keeps its signature and now receives the slugged stem, so the WebP renditions share the readable name (which is the third test above).

```csharp
using System.Globalization;
using Microsoft.EntityFrameworkCore;
using Triathlon.Web.Data;
using Triathlon.Web.Domain.Crm;

namespace Triathlon.Web.Services;

/// <summary>
/// Issues the next licence number for a year without locking anything.
/// <para>
/// Two things make this safe. First, it never touches the caller's unit of work: it takes an
/// <see cref="IServiceScopeFactory"/> and opens a scope of its own per attempt, so the athlete the
/// caller is in the middle of approving stays tracked and untouched, and an insert that lost a race
/// is discarded with its whole context. There is no <c>ChangeTracker.Clear()</c> here or anywhere
/// else in this codebase. Second, the counter row is claimed with a compare-and-swap — an UPDATE
/// carrying the value it expects to find — which is plain SQL on both providers, so no
/// <c>FOR UPDATE</c>, no <c>UPDLOCK</c> and no sequence object appears.
/// </para>
/// <para>
/// The unique index on <c>Athletes.LicenceNumber</c> is the backstop that would refuse a duplicate
/// outright. Because this commits outside the caller's transaction, an approval that fails afterwards
/// leaves a gap in the sequence. Gaps in a licence register are harmless; two athletes holding one
/// number is not.
/// </para>
/// </summary>
public sealed class LicenceNumbers(IServiceScopeFactory scopes)
{
    /// <summary>Enough for a realistic pile-up; the desk approves one at a time, a batch import ten.</summary>
    public const int MaxAttempts = 5;

    public static string Format(int year, int sequence) =>
        string.Create(CultureInfo.InvariantCulture, $"KSA-TRI-{year:0000}-{sequence:00000}");

    public async Task<string> NextAsync(int year, CancellationToken ct)
    {
        for (var attempt = 1; attempt <= MaxAttempts; attempt++)
        {
            await using var scope = scopes.CreateAsyncScope();
            var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();

            var current = await db.LicenceCounters.AsNoTracking()
                .Where(c => c.Year == year)
                .Select(c => (int?)c.Next)
                .SingleOrDefaultAsync(ct);

            if (current is null)
            {
                try
                {
                    // Sequence 1 is this caller's; the row is created already pointing at 2.
                    db.LicenceCounters.Add(new LicenceCounter { Year = year, Next = 2 });
                    await db.SaveChangesAsync(ct);
                    return Format(year, 1);
                }
                catch (DbUpdateException)
                {
                    // Another approval inserted the year's row first. The failed insert dies with
                    // this scope's context; the next attempt reads the row it created.
                    continue;
                }
            }

            var taken = current.Value;
            var claimed = await db.LicenceCounters
                .Where(c => c.Year == year && c.Next == taken)
                .ExecuteUpdateAsync(s => s.SetProperty(c => c.Next, taken + 1), ct);

            if (claimed == 1)
            {
                return Format(year, taken);
            }
        }

        throw new ContentValidationException("Id", "Validation_LicenceRetry", MaxAttempts);
    }
}
```

```csharp
    public async Task<string> ApproveAsync(Guid id, CancellationToken ct)
    {
        var athlete = await db.Athletes.SingleOrDefaultAsync(a => a.Id == id, ct)
            ?? throw new ContentValidationException("Id", "Validation_NotFound");

        if (athlete.ErasedAt is not null)
        {
            throw new ContentValidationException("Id", "Validation_AthleteErased");

        // Approving twice must not burn a second number.
        if (athlete.LicenceNumber is { } existing)

            return existing;

        // LicenceNumbers runs in a scope of its own, so this call cannot disturb the tracked athlete

        var issued = Today;

        athlete.DecisionReason = null;

        athlete.DecidedBy = await currentUser.GetNameAsync(ct);

    private async Task DecideAsync(
        Guid id, AthleteStatus status, string reason, string action, bool mail, CancellationToken ct)
    {
        if (string.IsNullOrWhiteSpace(reason))
        {
            throw new ContentValidationException("DecisionReason", "Validation_Required");
        }

        var athlete = await db.Athletes.SingleOrDefaultAsync(a => a.Id == id, ct)
            ?? throw new ContentValidationException("Id", "Validation_NotFound");

        if (athlete.ErasedAt is not null)
        {
            throw new ContentValidationException("Id", "Validation_AthleteErased");
        }

        var trimmed = reason.Trim();
        if (trimmed.Length > 512)
        {
            throw new ContentValidationException("DecisionReason", "Validation_MaxLength", 512);
        }

        var before = Audit.Snapshot(athlete);
        athlete.Status = status;
        athlete.DecisionReason = trimmed;
        athlete.DecidedAt = clock.GetUtcNow();
        athlete.DecidedBy = await currentUser.GetNameAsync(ct);

        await commit.ApplyAsync("Athlete", id, action, before, Audit.Snapshot(athlete), [], ct);

        if (mail)
        {
            jobs.Enqueue<AthleteMailJob>(job => job.SendRejectionAsync(id, CancellationToken.None));
        }
    }

    public async Task ReinstateAsync(Guid id, CancellationToken ct)
    {
        var athlete = await db.Athletes.SingleOrDefaultAsync(a => a.Id == id, ct)
            ?? throw new ContentValidationException("Id", "Validation_NotFound");

        var before = Audit.Snapshot(athlete);

        // A reinstated athlete who already holds a licence is approved again; one who never got that
        // far goes back to the queue rather than being approved without a number.
        athlete.Status = athlete.LicenceNumber is null ? AthleteStatus.Pending : AthleteStatus.Approved;
        athlete.DecisionReason = null;
        athlete.DecidedAt = clock.GetUtcNow();
        athlete.DecidedBy = await currentUser.GetNameAsync(ct);

        await commit.ApplyAsync("Athlete", id, "reinstate", before, Audit.Snapshot(athlete), [], ct);
    }

    {
        var athlete = await db.Athletes.IgnoreQueryFilters().SingleOrDefaultAsync(a => a.Id == id, ct)
            ?? throw new ContentValidationException("Id", "Validation_NotFound");

        athlete.FullName = Redacted;
        athlete.Email = string.Create(CultureInfo.InvariantCulture, $"erased+{id:N}@triathlon.invalid");
        athlete.Phone = null;
        athlete.NationalId = null;
        athlete.EmergencyName = null;
        athlete.EmergencyPhone = null;
        athlete.CityKey = null;
        athlete.EmailOptOut = true;
        athlete.EmailOptOutAt = clock.GetUtcNow();
        athlete.ErasedAt = clock.GetUtcNow();

        // No snapshot on either side: an audit row is the one place a PDPL erasure could put the
        // personal data straight back. The fact of the erasure is the record; the values are not.
        await commit.ApplyAsync("Athlete", id, "erase", new { Erased = true }, new { Erased = true }, [], ct);
    }

    public async Task ResendLicenceAsync(Guid id, CancellationToken ct)
    {
        var athlete = await db.Athletes.SingleOrDefaultAsync(a => a.Id == id, ct)
            ?? throw new ContentValidationException("Id", "Validation_NotFound");

        if (athlete.LicenceNumber is null)
        {
            throw new ContentValidationException("Id", "Validation_NoLicence");
        }

        await commit.ApplyAsync("Athlete", id, "resendLicence", null, new { athlete.LicenceNumber }, [], ct);

        jobs.Enqueue<AthleteMailJob>(job => job.SendLicenceAsync(id, CancellationToken.None));
    }

    public async Task SetEmailOptOutAsync(Guid id, bool optOut, CancellationToken ct)
    {
        var athlete = await db.Athletes.SingleOrDefaultAsync(a => a.Id == id, ct);
        if (athlete is null || athlete.EmailOptOut == optOut)
        {
            return;
        }

        var before = Audit.Snapshot(athlete);
        athlete.EmailOptOut = optOut;
        athlete.EmailOptOutAt = optOut ? clock.GetUtcNow() : null;

        await commit.ApplyAsync("Athlete", id, optOut ? "optout" : "optin",
            before, Audit.Snapshot(athlete), [], ct);
    }

    public Task<int> PendingCountAsync(CancellationToken ct) =>
        db.Athletes.CountAsync(a => a.Status == AthleteStatus.Pending, ct);

    private static string? Blank(string? value) => string.IsNullOrWhiteSpace(value) ? null : value.Trim();
```

```csharp
    /// <summary>
    /// The filter every athlete list and every athlete export share. Search runs against the
    /// denormalised SearchName column with the term normalised the same way it was (see
    /// SearchNormalizer): both sides are already lower case and free of tashkeel, so this is a plain
    /// Contains that translates identically on PostgreSQL and SQL Server.
    /// </summary>
    private IQueryable<Athlete> Filtered(AthleteFilter filter)
    {
        var query = filter.DeletedOnly
            ? db.Athletes.IgnoreQueryFilters().Where(a => a.DeletedAt != null)
            : db.Athletes.AsQueryable();

        if (filter.Status is { } status)
        {
            query = query.Where(a => a.Status == status);
        }

        if (filter.ClubId is { } clubId)
        {
            query = query.Where(a => a.ClubId == clubId);
        }

        if (!string.IsNullOrWhiteSpace(filter.Category))
        {
            query = query.Where(a => a.Category == filter.Category);
        }

        if (!string.IsNullOrWhiteSpace(filter.CityKey))
        {
            query = query.Where(a => a.CityKey == filter.CityKey);
        }

        var term = SearchNormalizer.Normalize(filter.Q);
        if (term.Length > 0)
        {
            query = query.Where(a => a.SearchName.Contains(term));
        }

        return query;
    }

    /// <summary>
    /// One projection for both the list and the export: the club and city names are joined here
    /// rather than looked up per row, so a screenful of athletes is one query, not twenty-six.
    /// </summary>
    private IQueryable<AthleteRow> Rows(IQueryable<Athlete> athletes) =>
        athletes.OrderByDescending(a => a.CreatedAt).ThenByDescending(a => a.Id)
            .Select(a => new AthleteRow(
                a,
                db.Clubs.IgnoreQueryFilters().Where(c => c.Id == a.ClubId).Select(c => c.NameEn).FirstOrDefault(),
                db.Clubs.IgnoreQueryFilters().Where(c => c.Id == a.ClubId).Select(c => c.NameAr).FirstOrDefault(),
                db.Cities.IgnoreQueryFilters().Where(c => c.Key == a.CityKey).Select(c => c.NameEn).FirstOrDefault(),
                db.Cities.IgnoreQueryFilters().Where(c => c.Key == a.CityKey).Select(c => c.NameAr).FirstOrDefault()))
            .AsNoTracking();

    public async Task<PagedResult<AthleteRow>> SearchAsync(AthleteFilter filter, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(filter);

        var query = Filtered(filter);
        var total = await query.CountAsync(ct);

        // Same clamp as PageQuery (Domain/Common/PagedResult.cs), so a crafted query string cannot
        // ask for an unbounded page. A page past the end returns nothing, not the first page.
        var page = Math.Max(filter.Page, 1);
        var size = Math.Clamp(filter.PageSize, 1, 100);

        var items = await Rows(query).Skip((page - 1) * size).Take(size).ToListAsync(ct);

        return new PagedResult<AthleteRow>(items, total, page, size);
    }

    /// <summary>
    /// The whole filtered set, unpaged. An export that stopped at the first page would quietly hand
    /// the desk an incomplete register, which is worse than a slow download; the athlete table is
    /// four figures at the outside, so one materialised list is the right trade.
    /// </summary>
    public async Task<IReadOnlyList<AthleteRow>> ExportAsync(AthleteFilter filter, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(filter);

        return await Rows(Filtered(filter)).ToListAsync(ct);
    }
```

```csharp
using System.Globalization;
using ClosedXML.Excel;
using Triathlon.Web.Domain.Events;

namespace Triathlon.Web.Services;

/// <summary>
/// The desk's exports. XLSX is a UTF-8 XML package, so Arabic survives without a BOM or a code page
/// — what has to be right is the sheet direction and that the header says both languages, because one
/// file is opened by both readers and the column count must not change with the culture. The national
/// identity number is deliberately absent from both sheets: it is encrypted in the database precisely
/// so that a copy of this data cannot carry it out of the building.
/// </summary>
public sealed class ExcelExport
{
    public const string ContentType = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet";

    private static readonly string[] RegistrationHeaders =
    [
        "# / م", "Full name / الاسم الكامل", "Email / البريد", "Phone / الهاتف",
        "Category / الفئة", "Club / النادي", "Status / الحالة", "Registered / تاريخ التسجيل",
    ];

    private static readonly string[] AthleteHeaders =
    [
        "# / م", "Licence / رقم الرخصة", "Full name / الاسم الكامل", "Email / البريد", "Phone / الهاتف",
        "Date of birth / تاريخ الميلاد", "Category / الفئة", "Club / النادي", "City / المدينة",
        "Status / الحالة", "Applied / تاريخ الطلب", "Issued / تاريخ الإصدار", "Expires / تاريخ الانتهاء",
    ];

    public byte[] Registrations(
        string eventTitleEn, string eventTitleAr, IReadOnlyList<EventRegistration> rows, string culture)
    {
        ArgumentNullException.ThrowIfNull(rows);

        var arabic = culture == "ar";
        using var workbook = new XLWorkbook();
        var sheet = workbook.AddWorksheet(SheetName(arabic ? eventTitleAr : eventTitleEn));
        sheet.RightToLeft = arabic;

        Header(sheet, RegistrationHeaders);

        for (var r = 0; r < rows.Count; r++)
        {
            var row = rows[r];
            sheet.Cell(r + 2, 1).Value = r + 1;
            sheet.Cell(r + 2, 2).Value = row.FullName;
            sheet.Cell(r + 2, 3).Value = row.Email;
            sheet.Cell(r + 2, 4).Value = row.Phone ?? "";
            sheet.Cell(r + 2, 5).Value = row.Category;
            sheet.Cell(r + 2, 6).Value = row.Club ?? "";
            sheet.Cell(r + 2, 7).Value = row.Status.ToString();
            sheet.Cell(r + 2, 8).Value = Riyadh(row.CreatedAt);
        }

        return Finish(workbook, sheet);
    }

    public byte[] Athletes(IReadOnlyList<AthleteRow> rows, string culture)
    {
        ArgumentNullException.ThrowIfNull(rows);

        var arabic = culture == "ar";
        using var workbook = new XLWorkbook();
        var sheet = workbook.AddWorksheet(arabic ? "الرياضيون" : "Athletes");
        sheet.RightToLeft = arabic;

        Header(sheet, AthleteHeaders);

        for (var r = 0; r < rows.Count; r++)
        {
            var (athlete, clubEn, clubAr, cityEn, cityAr) = rows[r];
            sheet.Cell(r + 2, 1).Value = r + 1;
            sheet.Cell(r + 2, 2).Value = athlete.LicenceNumber ?? "";
            sheet.Cell(r + 2, 3).Value = athlete.FullName;
            sheet.Cell(r + 2, 4).Value = athlete.Email;
            sheet.Cell(r + 2, 5).Value = athlete.Phone ?? "";
            sheet.Cell(r + 2, 6).Value = Iso(athlete.DateOfBirth);
            sheet.Cell(r + 2, 7).Value = athlete.Category;
            sheet.Cell(r + 2, 8).Value = (arabic ? clubAr : clubEn) ?? "";
            sheet.Cell(r + 2, 9).Value = (arabic ? cityAr : cityEn) ?? athlete.CityKey ?? "";
            sheet.Cell(r + 2, 10).Value = athlete.Status.ToString();
            sheet.Cell(r + 2, 11).Value = Riyadh(athlete.CreatedAt);
            sheet.Cell(r + 2, 12).Value = Iso(athlete.LicenceIssuedOn);
            sheet.Cell(r + 2, 13).Value = Iso(athlete.LicenceExpiresOn);
        }

        return Finish(workbook, sheet);
    }

    private static void Header(IXLWorksheet sheet, string[] headers)
    {
        for (var c = 0; c < headers.Length; c++)
        {
            sheet.Cell(1, c + 1).Value = headers[c];
        }

        sheet.Row(1).Style.Font.Bold = true;
    }

    private static byte[] Finish(XLWorkbook workbook, IXLWorksheet sheet)
    {
        sheet.SheetView.FreezeRows(1);
        sheet.RangeUsed()?.SetAutoFilter();
        sheet.Columns().AdjustToContents();

        using var stream = new MemoryStream();
        workbook.SaveAs(stream);
        return stream.ToArray();
    }

    /// <summary>Everything the federation prints is Riyadh time; the column stores UTC.</summary>
    private static string Riyadh(DateTimeOffset at) =>
        at.ToOffset(EventsService.RiyadhOffset).ToString("yyyy-MM-dd HH:mm", CultureInfo.InvariantCulture);

    /// <summary>Text, not a date cell: Excel would reinterpret a date against the reader's own locale.</summary>
    private static string Iso(DateOnly? date) =>
        date?.ToString("yyyy-MM-dd", CultureInfo.InvariantCulture) ?? "";

    /// <summary>Excel refuses \ / ? * [ ] : in a sheet name and caps it at 31 characters.</summary>
    private static string SheetName(string title)
    {
        var cleaned = new string(title.Where(ch => !"\\/?*[]:".Contains(ch, StringComparison.Ordinal)).ToArray()).Trim();
        if (cleaned.Length == 0)
        {
            cleaned = "Export";
        }

        return cleaned.Length <= 31 ? cleaned : cleaned[..31];
    }
}
```

```csharp
using System.Net.Mail;
using Microsoft.EntityFrameworkCore;
using Triathlon.Web.Data;
using Triathlon.Web.Domain.Common;
using Triathlon.Web.Domain.Crm;

namespace Triathlon.Web.Services;

/// <summary>
/// The federation's non-athlete relationships and the memos beside them. A separate aggregate from
/// <see cref="Athlete"/> and therefore a separate service; nothing here renders on a public page, so
/// every commit evicts no cache tags at all.
/// </summary>
public sealed class ContactsService(AppDbContext db, ContentCommit commit, TimeProvider clock)
{
    public const int MaxNoteLength = 2000;

    /// <summary>
    /// Tags as the audience filter compares them: lower case, trimmed, comma-separated, no blanks and
    /// no duplicates. Stored in one column rather than a join table because the whole vocabulary is a
    /// handful of words an officer types, and the only query over them is "has this one".
    /// </summary>
    public static string NormalizeTags(string? tags) =>
        string.Join(',', (tags ?? "")
            .Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
            .Select(tag => tag.ToLowerInvariant())
            .Distinct(StringComparer.Ordinal));

    public async Task<PagedResult<Contact>> SearchAsync(ContactFilter filter, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(filter);

        var query = filter.DeletedOnly
            ? db.Contacts.IgnoreQueryFilters().Where(c => c.DeletedAt != null)
            : db.Contacts.AsQueryable();

        if (filter.Type is { } type)
        {
            query = query.Where(c => c.Type == type);
        }

        if (!string.IsNullOrWhiteSpace(filter.Tag))
        {
            // Wrapped in commas on both sides so "gold" cannot match "goldsmith".
            var tag = "," + filter.Tag.Trim().ToLowerInvariant() + ",";
            query = query.Where(c => ("," + c.Tags + ",").Contains(tag));
        }

        var term = SearchNormalizer.Normalize(filter.Q);
        if (term.Length > 0)
        {
            query = query.Where(c => c.SearchName.Contains(term));
        }

        var total = await query.CountAsync(ct);
        var page = Math.Max(filter.Page, 1);
        var size = Math.Clamp(filter.PageSize, 1, 100);

        var items = await query.AsNoTracking()
            .OrderBy(c => c.SearchName).ThenBy(c => c.Id)
            .Skip((page - 1) * size).Take(size)
            .ToListAsync(ct);

        return new PagedResult<Contact>(items, total, page, size);
    }

    /// <summary>
    /// Notes are deliberately not included: a contact with two hundred memos would otherwise make
    /// opening the record an expensive query. The screen asks for them with <see cref="NotesAsync"/>.
    /// </summary>
    public Task<Contact?> ForEditAsync(Guid id, CancellationToken ct) =>
        db.Contacts.IgnoreQueryFilters().SingleOrDefaultAsync(c => c.Id == id, ct);

    public async Task<Contact> SaveAsync(ContactInput input, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(input);

        var errors = new ContentErrors();
        errors.RequireBoth("Name", input.NameEn, input.NameAr);
        errors.MaxLength("Name", input.NameEn, 128);
        errors.MaxLength("Name", input.NameAr, 128);
        errors.MaxLength("Organisation", input.OrganisationEn, 128);
        errors.MaxLength("Organisation", input.OrganisationAr, 128);
        errors.MaxLength("Email", input.Email, 256);
        errors.MaxLength("Phone", input.Phone, 32);

        if (!string.IsNullOrWhiteSpace(input.Email) && !MailAddress.TryCreate(input.Email.Trim(), out _))
        {
            errors.Add("Email", "Validation_Email");
        }

        // A contact nobody can reach is a row that will never be used; one channel is the minimum.
        if (string.IsNullOrWhiteSpace(input.Email) && string.IsNullOrWhiteSpace(input.Phone))
        {
            errors.Add("Email", "Validation_ContactChannel");
        }

        if (!Enum.IsDefined(input.Type))
        {
            errors.Add("Type", "Validation_Range");
        }

        var tags = NormalizeTags(input.Tags);
        errors.MaxLength("Tags", tags, 256);

        if (input.PreferredCulture is not ("en" or "ar"))
        {
            errors.Add("PreferredCulture", "Validation_Culture");
        }

        errors.ThrowIfAny();

        Contact contact;
        Dictionary<string, object?>? before = null;

        if (input.Id is { } id)
        {
            contact = await db.Contacts.SingleOrDefaultAsync(c => c.Id == id, ct)
                ?? throw new ContentValidationException("Id", "Validation_NotFound");
            before = Audit.Snapshot(contact);
        }
        else
        {
            contact = new Contact { NameEn = "", NameAr = "" };
            db.Contacts.Add(contact);
        }

        contact.NameEn = input.NameEn.Trim();
        contact.NameAr = input.NameAr.Trim();
        contact.OrganisationEn = Blank(input.OrganisationEn);
        contact.OrganisationAr = Blank(input.OrganisationAr);
        contact.Email = Blank(input.Email);
        contact.Phone = Blank(input.Phone);
        contact.Type = input.Type;
        contact.Tags = tags.Length == 0 ? null : tags;
        contact.PreferredCulture = input.PreferredCulture;

        await commit.ApplyAsync("Contact", contact.Id, before is null ? "create" : "update",
            before, Audit.Snapshot(contact), [], ct);

        return contact;
    }

    public async Task DeleteAsync(Guid id, CancellationToken ct)
    {
        var contact = await db.Contacts.SingleOrDefaultAsync(c => c.Id == id, ct);
        if (contact is null)
        {
            return;
        }

        // Remove, not a hard delete: StampInterceptor turns it into DeletedAt, so the notes stay
        // attached and come back with the contact if it is restored.
        db.Contacts.Remove(contact);
        await commit.ApplyAsync("Contact", id, "delete", Audit.Snapshot(contact), null, [], ct);
    }

    public async Task RestoreAsync(Guid id, CancellationToken ct)
    {
        var contact = await db.Contacts.IgnoreQueryFilters()
            .SingleOrDefaultAsync(c => c.Id == id && c.DeletedAt != null, ct);
        if (contact is null)
        {
            return;
        }

        contact.DeletedAt = null;
        await commit.ApplyAsync("Contact", id, "restore", null, Audit.Snapshot(contact), [], ct);
    }

    public async Task<IReadOnlyList<ContactNote>> NotesAsync(Guid contactId, CancellationToken ct) =>
        await db.ContactNotes.AsNoTracking()
            .Where(n => n.ContactId == contactId)
            .OrderByDescending(n => n.CreatedAt).ThenByDescending(n => n.Id)
            .Take(200)
            .ToListAsync(ct);

    /// <summary>
    /// Adds an internal memo. The body is plain text and is stored exactly as typed: a note is written
    /// by staff for staff and is rendered as text, never as markup, which removes the question of
    /// sanitising it. The author and the timestamp come from the entity stamps.
    /// </summary>
    public async Task<ContactNote> AddNoteAsync(Guid contactId, string body, CancellationToken ct)
    {
        if (string.IsNullOrWhiteSpace(body))
        {
            throw new ContentValidationException("Body", "Validation_Required");
        }

        var trimmed = body.Trim();
        if (trimmed.Length > MaxNoteLength)
        {
            throw new ContentValidationException("Body", "Validation_MaxLength", MaxNoteLength);
        }

        if (!await db.Contacts.AnyAsync(c => c.Id == contactId, ct))
        {
            throw new ContentValidationException("Id", "Validation_NotFound");
        }

        var note = new ContactNote { ContactId = contactId, Body = trimmed };
        db.ContactNotes.Add(note);

        // Logged against the contact, not the note, so the contact's own activity drawer shows it.
        await commit.ApplyAsync("Contact", contactId, "note", null, new { Note = Excerpt(trimmed) }, [], ct);

        return note;
    }

    public async Task DeleteNoteAsync(Guid noteId, CancellationToken ct)
    {
        var note = await db.ContactNotes.SingleOrDefaultAsync(n => n.Id == noteId, ct);
        if (note is null)
        {
            return;
        }

        var contactId = note.ContactId;
        var excerpt = Excerpt(note.Body);

        // A memo has no restore story, so this is a real delete rather than a soft one. Remove() would
        // be turned into a soft delete by StampInterceptor, so the entry is detached and removed
        // through ExecuteDelete instead — outside the unit of work, then logged.
        await db.ContactNotes.Where(n => n.Id == noteId).ExecuteDeleteAsync(ct);
        db.Entry(note).State = EntityState.Detached;

        await commit.ApplyAsync("Contact", contactId, "noteDelete", new { Note = excerpt }, null, [], ct);
    }

    public async Task SetEmailOptOutAsync(Guid id, bool optOut, CancellationToken ct)
    {
        var contact = await db.Contacts.SingleOrDefaultAsync(c => c.Id == id, ct);
        if (contact is null || contact.EmailOptOut == optOut)
        {
            return;
        }

        var before = Audit.Snapshot(contact);
        contact.EmailOptOut = optOut;
        contact.EmailOptOutAt = optOut ? clock.GetUtcNow() : null;

        await commit.ApplyAsync("Contact", id, optOut ? "optout" : "optin",
            before, Audit.Snapshot(contact), [], ct);
    }

    /// <summary>Enough of a note to recognise it in the audit trail, never the whole memo.</summary>
    private static string Excerpt(string body) => body.Length <= 80 ? body : body[..80] + "…";

    private static string? Blank(string? value) => string.IsNullOrWhiteSpace(value) ? null : value.Trim();
}
```

```csharp
using System.Security.Cryptography;
using Microsoft.AspNetCore.DataProtection;
using Microsoft.Extensions.Options;
using Triathlon.Web.Data.Crm;
using Triathlon.Web.Domain.Crm;
using Triathlon.Web.Infrastructure;

namespace Triathlon.Web.Services;

/// <summary>
/// The token in an unsubscribe link. It is derived, not stored: the recipient's kind and id are
/// protected with a dedicated data-protection purpose, which gives an opaque, tamper-evident,
/// URL-safe string with no extra column, no lookup index and no expiry — an unsubscribe link that
/// stops working is worse than useless. Rotating the key ring is how a link is ever revoked.
/// <para>
/// Two URLs come out of the same token. <see cref="PageLink"/> is what a human sees in the footer: a
/// confirmation page with a button. <see cref="PostUrl"/> is what goes in the RFC 8058
/// <c>List-Unsubscribe</c> header, which mail clients POST to directly. Neither is a GET that
/// mutates, because a GET that mutates is fired by every link scanner that pre-fetches a URL.
/// </para>
/// </summary>
public sealed class UnsubscribeTokens(IDataProtectionProvider provider, IOptions<SiteOptions> site)
{
    /// <summary>The reserved public slug; also in <c>PublicSite.ReservedSlugs</c>.</summary>
    public const string PagePath = "unsubscribe";

    /// <summary>The one endpoint that actually changes anything. Always POST.</summary>
    public const string PostPath = "/api/unsubscribe";

    private readonly IDataProtector _protector = provider.CreateProtector(CrmProtection.UnsubscribePurpose);

    public string Create(RecipientKind kind, Guid id) => _protector.Protect($"{kind}:{id:N}");

    public bool TryRead(string? token, out RecipientKind kind, out Guid id)
    {
        kind = RecipientKind.Athlete;
        id = Guid.Empty;

        if (string.IsNullOrWhiteSpace(token))
        {
            return false;
        }

        string payload;
        try
        {
            payload = _protector.Unprotect(token);
        }
        catch (CryptographicException)
        {
            // Forged, truncated, or protected with a key ring this instance no longer has.
            return false;
        }
        catch (FormatException)
        {
            return false;
        }

        var parts = payload.Split(':', 2);
        return parts.Length == 2 && Enum.TryParse(parts[0], out kind) && Guid.TryParseExact(parts[1], "N", out id);
    }

    public string PageLink(RecipientKind kind, Guid id, string culture) =>
        $"{Origin}/{(culture == "ar" ? "ar" : "en")}/{PagePath}?t={Create(kind, id)}";

    public string PostUrl(RecipientKind kind, Guid id) => $"{Origin}{PostPath}?t={Create(kind, id)}";

    private string Origin => site.Value.BaseUrl.TrimEnd('/');
}
```

```csharp
using Hangfire;
using Microsoft.EntityFrameworkCore;
using Triathlon.Web.Data;
using Triathlon.Web.Domain.Crm;
using Triathlon.Web.Jobs;

namespace Triathlon.Web.Services;

/// <summary>
/// Composes a bulk message, freezes its audience into rows, and hands the sending to
/// <see cref="EmailBlastJob"/>. Materialising the audience at send time is what makes the send
/// resumable and auditable: the officer can see exactly who was written to months later, even after
/// the filter that selected them would return a different set.
/// </summary>
public sealed class EmailBlastService(
    AppDbContext db, ContentGuard guard, ContentCommit commit, IBackgroundJobClient jobs, TimeProvider clock)
{
    public async Task<AudienceCount> PreviewAsync(BlastAudience audience, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(audience);

        var athletes = audience.IncludeAthletes ? await Athletes(audience).CountAsync(ct) : 0;
        var contacts = audience.IncludeContacts ? await Contacts(audience).CountAsync(ct) : 0;

        // Counted separately so the screen can say "N will not be written to" rather than leaving the
        // officer to wonder why the number is smaller than the club roster.
        var optedOutAthletes = audience.IncludeAthletes
            ? await AthletesBeforeOptOut(audience).CountAsync(a => a.EmailOptOut, ct)
            : 0;
        var optedOutContacts = audience.IncludeContacts
            ? await ContactsBeforeOptOut(audience).CountAsync(c => c.EmailOptOut, ct)
            : 0;

        return new AudienceCount(athletes, contacts, optedOutAthletes + optedOutContacts);
    }

    public async Task<EmailBlast> SendAsync(EmailBlastInput input, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(input);

        var errors = new ContentErrors();
        errors.RequireBoth("Subject", input.SubjectEn, input.SubjectAr);
        errors.MaxLength("Subject", input.SubjectEn, 256);
        errors.MaxLength("Subject", input.SubjectAr, 256);
        errors.RequireBoth("Body", input.BodyEn, input.BodyAr);

        if (!input.Audience.IncludeAthletes && !input.Audience.IncludeContacts)
        {
            errors.Add("Audience", "Validation_EmptyAudience");
        }

        errors.ThrowIfAny();

        var bodyEn = guard.Html(input.BodyEn) ?? throw new ContentValidationException("Body", "Validation_BodyEmpty");
        var bodyAr = guard.Html(input.BodyAr) ?? throw new ContentValidationException("Body", "Validation_BodyEmpty");

        var recipients = await MaterialiseAsync(input.Audience, ct);
        if (recipients.Count == 0)
        {
            throw new ContentValidationException("Audience", "Validation_EmptyAudience");
        }

        var blast = new EmailBlast
        {
            SubjectEn = input.SubjectEn.Trim(),
            SubjectAr = input.SubjectAr.Trim(),
            BodyEn = bodyEn,
            BodyAr = bodyAr,
            IncludeAthletes = input.Audience.IncludeAthletes,
            AudienceStatus = input.Audience.Status,
            AudienceClubId = input.Audience.ClubId,
            AudienceCityKey = input.Audience.CityKey,
            AudienceCategory = input.Audience.Category,
            IncludeContacts = input.Audience.IncludeContacts,
            AudienceContactType = input.Audience.ContactType,
            AudienceTag = input.Audience.Tag,
            Status = BlastStatus.Sending,
            RecipientCount = recipients.Count,
            StartedAt = clock.GetUtcNow(),
        };

        db.EmailBlasts.Add(blast);
        foreach (var recipient in recipients)
        {
            recipient.BlastId = blast.Id;
            db.EmailBlastRecipients.Add(recipient);
        }

        // One unit of work: the blast, its recipients and the audit row commit together, so a blast
        // can never exist without the list of people it is about to write to.
        await commit.ApplyAsync("EmailBlast", blast.Id, "send", null,
            new { blast.SubjectEn, blast.SubjectAr, blast.RecipientCount }, [], ct);

        jobs.Enqueue<EmailBlastJob>(job => job.RunAsync(blast.Id, CancellationToken.None));

        return blast;
    }

    public async Task<IReadOnlyList<EmailBlast>> HistoryAsync(int take, CancellationToken ct) =>
        await db.EmailBlasts.AsNoTracking()
            .OrderByDescending(b => b.CreatedAt).ThenByDescending(b => b.Id)
            .Take(Math.Clamp(take, 1, 100))
            .ToListAsync(ct);

            .FirstOrDefaultAsync(ct);

        db.EmailBlasts.AsNoTracking().SingleOrDefaultAsync(b => b.Id == id, ct);

    public async Task<IReadOnlyList<EmailBlastRecipient>> RecipientsAsync(
        Guid blastId, BlastRecipientStatus? status, int take, CancellationToken ct)
    {
        var query = db.EmailBlastRecipients.AsNoTracking().Where(r => r.BlastId == blastId);
        if (status is { } value)
        {
            query = query.Where(r => r.Status == value);
        }

        return await query
            .OrderBy(r => r.CreatedAt).ThenBy(r => r.Id)
            .Take(Math.Clamp(take, 1, 500))
            .ToListAsync(ct);
    }

    /// <summary>
    /// Turns the audience filter into rows, de-duplicated by email so somebody who is both an athlete
    /// and a listed contact gets one message rather than two.
    /// </summary>
    private async Task<List<EmailBlastRecipient>> MaterialiseAsync(BlastAudience audience, CancellationToken ct)
    {
        var seen = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        var recipients = new List<EmailBlastRecipient>();

        if (audience.IncludeAthletes)
        {
            var rows = await Athletes(audience)
                .Select(a => new { a.Id, a.Email, a.PreferredCulture })
                .ToListAsync(ct);

            foreach (var row in rows.Where(row => seen.Add(row.Email)))
            {
                recipients.Add(new EmailBlastRecipient
                {
                    Kind = RecipientKind.Athlete, RecipientId = row.Id,
                    Email = row.Email, Culture = row.PreferredCulture,
                    Status = BlastRecipientStatus.Pending,
                });
            }
        }

        if (audience.IncludeContacts)
        {
            var rows = await Contacts(audience)
                .Select(c => new { c.Id, c.Email, c.PreferredCulture })
                .ToListAsync(ct);

            foreach (var row in rows.Where(row => row.Email is not null && seen.Add(row.Email)))
            {
                recipients.Add(new EmailBlastRecipient
                {
                    Kind = RecipientKind.Contact, RecipientId = row.Id,
                    Email = row.Email!, Culture = row.PreferredCulture,
                    Status = BlastRecipientStatus.Pending,
                });
            }
        }

        return recipients;
    }

    private IQueryable<Athlete> AthletesBeforeOptOut(BlastAudience audience)
    {
        var query = db.Athletes.Where(a => a.ErasedAt == null && a.Email != "");

        if (audience.Status is { } status)

            query = query.Where(a => a.Status == status);
        }

        if (audience.ClubId is { } clubId)
        {
            query = query.Where(a => a.ClubId == clubId);
        }

        if (!string.IsNullOrWhiteSpace(audience.CityKey))
        {
            query = query.Where(a => a.CityKey == audience.CityKey);
        }

        if (!string.IsNullOrWhiteSpace(audience.Category))
        {
            query = query.Where(a => a.Category == audience.Category);
        }

        return query;
    }

    private IQueryable<Athlete> Athletes(BlastAudience audience) =>
        AthletesBeforeOptOut(audience).Where(a => !a.EmailOptOut);

    private IQueryable<Contact> ContactsBeforeOptOut(BlastAudience audience)
    {
        var query = db.Contacts.Where(c => c.Email != null && c.Email != "");

        if (audience.ContactType is { } type)

        }

        if (!string.IsNullOrWhiteSpace(audience.Tag))
        {
            var tag = "," + audience.Tag.Trim().ToLowerInvariant() + ",";

        }
```

```csharp
using Triathlon.Web.Domain.Crm;
using Triathlon.Web.Services;

namespace Triathlon.Web.Jobs;

/// <summary>
/// Sends one blast, a hundred messages at a time, one minute apart. The pacing is not decoration: a
/// shared SMTP relay throttles far below what a tight loop would attempt, and a paced send is
/// resumable after a restart because all the state is in rows rather than in a loop variable.
/// </summary>
public sealed class EmailBlastJob(
    AppDbContext db, IEmailSender sender, UnsubscribeTokens tokens,
    IBackgroundJobClient jobs, TimeProvider clock, ILogger<EmailBlastJob> log)
{
    public const int BatchSize = 100;

    public static readonly TimeSpan BatchInterval = TimeSpan.FromMinutes(1);

    /// <summary>
    /// <see cref="DisableConcurrentExecutionAttribute"/> so a Hangfire retry cannot overlap the run it
    /// is retrying and write to the same hundred people twice. Ten minutes is far more than a batch
    /// takes and far less than a stuck worker's lease.
    /// </summary>
    [DisableConcurrentExecution(timeoutInSeconds: 600)]
    [AutomaticRetry(Attempts = 3)]
    public async Task RunAsync(Guid blastId, CancellationToken ct)
    {
        var blast = await db.EmailBlasts.SingleOrDefaultAsync(b => b.Id == blastId, ct);
        if (blast is null || blast.Status is not BlastStatus.Sending)
        {
            log.LogInformation("Blast {Id} is not sending; nothing to do.", blastId);
            return;
        }

        // Counted before the batch is touched: "pending minus what this run takes" is the remainder,
        // and a LINQ "not in this batch" predicate would not translate to SQL.
        var pending = await db.EmailBlastRecipients
            .CountAsync(r => r.BlastId == blastId && r.Status == BlastRecipientStatus.Pending, ct);

        // CreatedAt then Id: the order they were queued in, stable on both providers.
        var batch = await db.EmailBlastRecipients
            .Where(r => r.BlastId == blastId && r.Status == BlastRecipientStatus.Pending)
            .OrderBy(r => r.CreatedAt).ThenBy(r => r.Id)
            .Take(BatchSize)
            .ToListAsync(ct);

        foreach (var recipient in batch)
        {
            // Re-checked here, not only at queueing time: somebody who unsubscribed while the blast
            // was pacing itself must not receive the rest of it.
            if (await OptedOutAsync(recipient, ct))
            {
                recipient.Status = BlastRecipientStatus.Skipped;
                blast.SkippedCount++;
            }
            else
            {
                try
                {
                    await sender.SendAsync(Compose(blast, recipient), ct);
                    recipient.Status = BlastRecipientStatus.Sent;
                    recipient.SentAt = clock.GetUtcNow();
                    blast.SentCount++;
                }
                catch (Exception ex) when (ex is not OperationCanceledException)
                {
                    recipient.Status = BlastRecipientStatus.Failed;
                    recipient.Error = ex.Message.Length > 512 ? ex.Message[..512] : ex.Message;
                    blast.FailedCount++;
                    log.LogWarning(ex, "Blast {Blast} could not reach recipient {Recipient}.", blastId, recipient.Id);
                }
            }

            // One save per recipient. The "single SaveChanges per unit of work" rule is about an
            // editor's save, where a partial write would corrupt one record; this is a batch job,
            // where saving once at the end would re-send the whole batch to everybody after a crash.
            await db.SaveChangesAsync(ct);
        }

        var remaining = pending - batch.Count;

        if (remaining <= 0)
        {
            blast.Status = blast.SentCount == 0 && blast.FailedCount > 0 ? BlastStatus.Failed : BlastStatus.Sent;
            blast.CompletedAt = clock.GetUtcNow();
            await db.SaveChangesAsync(ct);
            return;
        }

        jobs.Schedule<EmailBlastJob>(job => job.RunAsync(blastId, CancellationToken.None), BatchInterval);
    }

    private Task<bool> OptedOutAsync(EmailBlastRecipient recipient, CancellationToken ct) =>
        recipient.Kind == RecipientKind.Athlete
            ? db.Athletes.AnyAsync(a => a.Id == recipient.RecipientId && (a.EmailOptOut || a.ErasedAt != null), ct)
            : db.Contacts.AnyAsync(c => c.Id == recipient.RecipientId && c.EmailOptOut, ct);

    /// <summary>
    /// The message as one recipient receives it: their own language, the sanitised body, a visible
    /// unsubscribe link, and the RFC 8058 header pair that lets a mail client's own unsubscribe button
    /// POST to the same endpoint. The label here and <c>L["Unsubscribe"]</c> on the compose screen's
    /// preview must read the same, which is why both are listed in the 4.2.D resx table.
    /// </summary>
    private EmailMessage Compose(EmailBlast blast, EmailBlastRecipient recipient)
    {
        var arabic = recipient.Culture == "ar";
        var subject = arabic ? blast.SubjectAr : blast.SubjectEn;
        var body = arabic ? blast.BodyAr : blast.BodyEn;

        var pageLink = tokens.PageLink(recipient.Kind, recipient.RecipientId, recipient.Culture);
        var label = arabic ? "إلغاء الاشتراك" : "Unsubscribe";

        var html = body + $"<hr><p><a href=\"{pageLink}\">{label}</a></p>";
        var text = arabic ? $"{label}: {pageLink}" : $"{label}: {pageLink}";

        var headers = new Dictionary<string, string>(StringComparer.Ordinal)
        {
            ["List-Unsubscribe"] = $"<{tokens.PostUrl(recipient.Kind, recipient.RecipientId)}>",
            ["List-Unsubscribe-Post"] = "List-Unsubscribe=One-Click",
        };

        return new EmailMessage(recipient.Email, subject, html, text, Attachments: null, Headers: headers);
    }
}
```

```csharp
/// <summary>

    public bool Done { get; private set; }

        Done = done;
        Token = tokens.TryRead(t, out _, out _) ? t : null;
    }
```

`src/Triathlon.Web/Api/PublicApi.cs` — inside `MapPublicApi`, beside the two existing POSTs:

```csharp
        // POST, never GET: an unsubscribe that fires on a GET is triggered by link scanners that
        // pre-fetch URLs. Antiforgery is disabled deliberately — the caller is either our own
        // confirmation page (whose only credential is the token itself) or, under RFC 8058, the
        // recipient's mail client posting the List-Unsubscribe URL with no cookies at all. The token
        // is the authorisation; the action is idempotent and only ever reduces what we send.
        api.MapPost("/unsubscribe", async (
            [FromQuery(Name = "t")] string? t,
            [FromQuery] string? culture,
            UnsubscribeTokens tokens,
            CrmService crm,
            ContactsService contacts,
            CancellationToken ct) =>
        {
            var target = culture == "ar" ? "ar" : "en";

            if (!tokens.TryRead(t, out var kind, out var id))
            {
                return Results.Redirect($"/{target}/{UnsubscribeTokens.PagePath}");
            }

            if (kind == RecipientKind.Athlete)
            {
                await crm.SetEmailOptOutAsync(id, true, ct);
            }
            else
            {
                await contacts.SetEmailOptOutAsync(id, true, ct);
            }

            return Results.Redirect($"/{target}/{UnsubscribeTokens.PagePath}?done=true");
        })
        .DisableAntiforgery()
        .RequireRateLimiting(RateLimitSetup.PublicPost);
```
