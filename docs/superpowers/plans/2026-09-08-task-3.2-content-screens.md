# Task 3.2 — Content screens, featured-event layout, dashboard QA, Week 4 gate (step-level plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every content type an editor manages gets a list screen and an edit screen in the Blazor dashboard, built on the Task 3.1 write services and component kit; the Week 4 gate is proven end to end (publish → visible on the public site within one request; activity log shows before/after; Editor cannot open Users) in both text directions, and the session is chained.

**Architecture:** One list-page pattern (`EntityTable` component: search box, "show deleted" switch, `MudTable` with status chip + row actions) and one edit-page pattern (`EditShell`: title, sections, `PublishBar`, `ActivityDrawer`, error banner) are written once (Task 3.2.A) and reused by every screen. Each screen maps 1:1 onto a service's `…ForEditAsync` / `Save…Async` / `SetPublishedAsync` / `Delete…Async` / `Restore…Async` methods from the Task 3.1 plan; screens hold no persistence logic. Interactive server rendering; every string from `DashboardStrings`.

**Tech Stack:** Blazor interactive server, MudBlazor 9.9.0, the Task 3.1 kit (`BilingualField`, `BilingualRichText`, `SlugField`, `MediaPicker`, `FileUpload`, `PublishBar`, `ConfirmDialog`, `ActivityDrawer`), playwright-cli for evidence.

**Spec:** `docs/superpowers/plans/2026-09-06-triathlon-platform-ultra-plan.md` Task 3.2 + Week 4 gate; `docs/HANDOVER.md` §7 (chain), §8 Week 4; `docs/superpowers/plans/2026-09-08-task-3.1-dashboard-foundations.md` (services + kit contracts); `.claude/agents/stf-dashboard-ux.md` (principles); `docs/qa/2026-09-07-week2-3-public-site.md` P2-18.

## Global Constraints

As in the Task 3.1 plan. Additional:

- Screens call services only; no `AppDbContext` in a `.razor` file. `ContentValidationException` from a save is caught by `EditShell` and shown next to the field (`Field`) or as the banner.
- Every list and edit screen: `[Authorize(Policy = Policies.Content)]` (Settings: `Policies.Admin`). Routes are `/dashboard/{plural}` and `/dashboard/{plural}/{id:guid}` plus `/dashboard/{plural}/new`.
- RTL: only logical CSS in `dashboard.css`; MudBlazor mirrors through `MudRTLProvider`. Every screen is checked in both directions before its commit (one `playwright-cli` screenshot each, from the scratchpad).
- Toasts through `ISnackbar`: `L["Saved"]`, `L["PublishedToast"]`, `L["ErrorSaving"]`.
- `dotnet test` green on PostgreSQL and (`STF_TEST_DB=SqlServer`) SQL Server before the gate commit.

## Decisions recorded by this plan

1. **One table, one shell.** `EntityTable<TItem>` and `EditShell` are the only page chrome; a screen that needs something the shell lacks extends the shell, not itself.
2. **Blocks editor.** A page's blocks are edited in place as an ordered list of expandable panels (`MudExpansionPanels`), one per block, with move-up/move-down/delete and an "Add block" menu by `BlockType`. Repeating items (`BlockItem`) are edited as a nested list of small forms (`ItemsEditor`), never as raw JSON — the JSON stays an implementation detail of `ContentService`.
3. **Navigation** is one screen with three tabs (Header, Footer · Compete, Footer · Involved); each tab is a reorderable list saved whole through `SaveNavigationAsync`. Reorder = up/down buttons (keyboard-reachable; drag is a nicety, not a requirement).
4. **Event categories** are chips (`MudChipSet` with a free-text add) over the known keys from `EventCategories`; results are a small editable grid; the gallery is a `MediaPicker` list.
5. **Statistics** is one screen with three sections (KPIs table with inline edit, regions list, growth list); `Source = Computed` rows show the value read-only with a "computed nightly" hint.
6. **Preview** links open the public page in the current dashboard culture (`/{en|ar}/…`). Draft content has no public preview route in Week 4 (output cache + anonymous pages); the preview link is shown only for published items, and the shell says so for drafts (`L["PreviewAfterPublish"]`).
7. **Featured event (P2-18).** An orphan last card in the 3-column events grid stretches across the row (`grid-column: 1 / -1`) and switches to a horizontal layout at ≥ 980 px; nothing changes for full rows. CSS only.
8. **Users** stays the Task 3.1.G stub (Admin policy) until Week 5; the gate's "Editor cannot open Users" is proven against it.

```razor
@page "/dashboard/events/new"
@page "/dashboard/events/{Id:guid}"
@attribute [Authorize(Policy = Policies.Content)]
@inject EventsService Events
@inject IStringLocalizer<DashboardStrings> L
@inject ISnackbar Snackbar
@inject NavigationManager Nav
@inject IDialogService Dialogs

<PageTitle>@title</PageTitle>

<EditShell Title="@title" BackHref="dashboard/events" IsNew="@(Id is null)" IsPublished="@model.IsPublished" IsDirty="@dirty" IsSaving="@saving"
           Error="@error" FieldErrors="@fieldErrors" PreviewUrl="@PreviewUrl" LastUpdatedAt="@loaded?.UpdatedAt" LastUpdatedBy="@loaded?.UpdatedBy"
           OnSaveDraft="@(() => SaveAsync(publish: false))" OnPublish="@(() => SaveAsync(publish: true))" OnUnpublish="@UnpublishAsync" OnDelete="@DeleteAsync"
           ActivityEntity="Event" ActivityId="@Id">
    <MudText Typo="Typo.h6" Class="mt-4">@L["Basics"]</MudText>
    <BilingualField Label="@L["Title"]" @bind-En="model.TitleEn" @bind-Ar="model.TitleAr" />
    <SlugField @bind-Value="model.Slug" Source="@model.TitleEn" />
    @* … remaining sections exactly per the field list … *@
</EditShell>

@code {
    [Parameter] public Guid? Id { get; set; }

    private sealed class Model { /* one mutable property per EventInput member, same names and types; Gallery/Results as List<…Input> */ }

    private Model model = new();
    private Event? loaded;
    private bool dirty, saving;
    private string? error;
    private readonly Dictionary<string, string> fieldErrors = new(StringComparer.Ordinal);
    private string title => Id is null ? L["NewEvent"] : (loaded is null ? "" : loaded.TitleEn);
    private string? PreviewUrl => loaded is { IsPublished: true } ? $"/{Culture}/events/{loaded.Slug}" : null;
    private static string Culture => System.Globalization.CultureInfo.CurrentUICulture.TwoLetterISOLanguageName == "ar" ? "ar" : "en";

    protected override async Task OnParametersSetAsync()
    {
        if (Id is { } id) { loaded = await Events.ForEditAsync(id, CancellationToken.None); if (loaded is null) { Nav.NavigateTo("dashboard/not-found"); return; } model = Model.From(loaded); }
        dirty = false;
    }

    private async Task SaveAsync(bool publish)
    {
        saving = true; error = null; fieldErrors.Clear();
        try
        {
            var input = model.ToInput(publish || (loaded?.IsPublished ?? false) && !publish ? model.IsPublished : publish);
            if (Id is { } id) { await Events.UpdateAsync(id, input, CancellationToken.None); loaded = await Events.ForEditAsync(id, CancellationToken.None); }
            else { var created = await Events.CreateAsync(input, CancellationToken.None); Nav.NavigateTo($"dashboard/events/{created.Id}"); return; }
            model = Model.From(loaded!); dirty = false;
            Snackbar.Add(publish ? L["PublishedToast"] : L["Saved"], Severity.Success);
        }
        catch (ContentValidationException ex) { EditShell.Handle(ex, out error, fieldErrors); Snackbar.Add(L["ErrorSaving"], Severity.Error); }
        finally { saving = false; }
    }

    private async Task UnpublishAsync() { if (Id is { } id) { await Events.SetPublishedAsync(id, false, CancellationToken.None); loaded = await Events.ForEditAsync(id, CancellationToken.None); model = Model.From(loaded!); Snackbar.Add(L["Saved"], Severity.Success); } }

    private async Task DeleteAsync()
    {
        if (Id is not { } id || loaded is null) return;
        if (!await ConfirmDialog.ShowAsync(Dialogs, L["Delete"], L["DeleteEventConfirm"], L["Delete"], danger: true, typeToConfirm: loaded.Slug)) return;
        await Events.DeleteAsync(id, CancellationToken.None);
        Snackbar.Add(L["Saved"], Severity.Success);
        Nav.NavigateTo("dashboard/events");
    }
}
```

`SaveAsync`'s published flag: Save draft keeps the current published state for an already-published item (editing a live event does not unpublish it); Publish sets true. Write that as `var published = publish || (loaded?.IsPublished ?? false);` — replace the convoluted expression above with exactly this line.
