# Task 3.1 — Dashboard foundations: safety rails, write services, jobs, carry-overs, component kit (step-level plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything the Week 4 content screens stand on: the eviction contract, the HTML and file-path guards, soft-delete cascade + restore for every aggregate, write methods on every service (one save, one activity-log row, one eviction per mutation), the two Hangfire jobs, the Weeks 2–3 carry-overs, and the bilingual MudBlazor component kit with an RTL dashboard shell.

**Architecture:** Write methods live on the existing per-aggregate services (`EventsService`, `ContentService`, `DocumentsService`, `StatsService`, `CrmService`, new `MediaService`). Each mutation is one unit of work: mutate tracked entities → `ContentCommit.ApplyAsync(...)` which calls `IActivityLogger.LogAsync` (the single `SaveChanges`) and then evicts the tags the change touched. Editor-written HTML and file paths pass through `ContentGuard` on every save. The dashboard shell is Blazor interactive-server + MudBlazor 9 with `MudRTLProvider`; every string comes from `Resources/DashboardStrings.{en,ar}.resx`.

**Tech Stack:** ASP.NET Core 10, EF Core 10 (PostgreSQL + SQL Server migration pairs), MudBlazor 9.9.0, HtmlSanitizer 9.2.1039, Quill 2.0.3 (vendored), Hangfire 1.8, bunit 2.9.0, xUnit + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-09-06-triathlon-platform-design.md` §5–§7; `docs/superpowers/plans/2026-09-06-triathlon-platform-ultra-plan.md` "Week 4"; `docs/HANDOVER.md` §8 Week 4 prompt + §9 carry-overs; `docs/adr/0001-soft-delete-cascade.md`.

## Decisions recorded by this plan (read before coding)

1. **Reserved slugs.** `PublicSite.ReservedSlugs` is the one list of first path segments the generic content page must never serve: every dedicated public route plus infrastructure paths. `PublicSite.CompanionPageSlugs` (`home`, `rules`, `training`, `governance`, `statistics`) are the slugs a CMS `Page` may still carry because a dedicated page renders its blocks. `Slugs.IsValid` (`^[a-z0-9]+(-[a-z0-9]+)*$`, ≤ 128) applies to every slugged entity. Used by `Content.cshtml.cs` (routing), `SeoEndpoints` (sitemap dedup) and `ContentService` (validation).
2. **`ContentGuard`** (scoped service) is the only way editor input reaches storage: `Html(string?)` sanitises through HtmlSanitizer with a fixed allow-list (tags `p br strong em b i u s ul ol li a h2 h3 h4 blockquote table thead tbody tr th td span div sup sub`, attributes `href title target rel class`, schemes `http https mailto tel` + site-relative paths, no `style`, no `id`, no event handlers); `FilePath(string?)` accepts only `/docs/...` or `{MediaOptions.NormalizedPublicPrefix}/...` with no `..`, no `//`, no query, no scheme — anything else throws `ContentValidationException`. Applied to every field a view renders with `Html.Raw` (block bodies, block item bodies, home hero title + lead, news bodies, guide chapters) and every stored file path.
3. **`ContentCommit`** = the unit of work's tail: `ApplyAsync(entity, id, action, before, after, tags, ct)` → `IActivityLogger.LogAsync` (the single `SaveChangesAsync`) → `IOutputCacheStore.EvictAsync(tags)`. Services never call `SaveChangesAsync` on a dashboard path themselves. `Audit.Snapshot(entity)` produces the before/after dictionaries (scalars only, stamps excluded) so the diff in the activity log is readable.
4. **Delete / restore (ADR 0001).** `DeleteAsync` soft-deletes the aggregate and its owned children in the same save; `RestoreAsync` clears `DeletedAt` on the parent and on children whose `DeletedAt` falls within the same second. List queries take `includeDeleted` (`IgnoreQueryFilters().Where(x => x.DeletedAt != null)` for the trash view). Athletes have no children; registrations are never cascaded.
5. **Base output-cache policy** sets `SetVaryByQuery([])` so only pages that declare `VaryByQueryKeys` vary; `?utm=…` no longer fragments the cache. The `/api/timeline` and `/api/calendar.ics` endpoints keep their explicit `SetVaryByQuery`.
6. **Download endpoints** answer 404 (and log a warning) when the stored path fails `ContentGuard.IsSiteFilePath`, so a corrupted row can never become an open redirect.
7. **Media library.** `MediaAsset` (kind, path, content type, size, variants JSON, alt EN/AR, original name) is written by `MediaService.UploadAsync`, which wraps `IFileStore.SaveAsync`. Migration `MediaAssets`. Every dashboard upload — gallery image, hero, results PDF, document, rule, guide — goes through it, so the media screen lists everything.
8. **Site settings.** `SiteSetting(Key unique, ValueEn, ValueAr)`; keys `contact.email`, `contact.website`, `contact.x`, `footer.blurb`. The footer reads them through `ContentService.SettingsAsync`; a save evicts `site`. Migration `SiteSettings`. (Admin-panel settings — users, roles — stay Week 5.)
9. **Email through Hangfire.** `EmailJob.SendAsync(EmailMessage)` is the only sender callers enqueue; `CrmService.ApplyAsync` enqueues instead of sending inline. Tests replace `IBackgroundJobClient` with `InlineJobClient`, which runs the job synchronously on the calling thread, so `app.Emails` stays assertable.
10. **Computed KPIs.** `ComputedKpisJob.RunAsync` recomputes every `Kpi` with `Source == Computed` from a fixed key map (`athletes`, `participants`, `tournaments`, `community`, `clubs`), logs a `system` activity row per changed value and evicts `stats` + `home`. Registered as recurring job `computed-kpis`, cron `0 23 * * *` UTC (02:00 Riyadh). Unknown computed keys are skipped with a warning.
11. **Structural vs demo seed.** `SeedStructure` (navigation, committees, the five CMS pages, the ten KPI rows with `Value = 0`, the four site settings) runs when `Database:SeedStructure` is true (default true; idempotent per table/key) so production boots with a header and editable rows. `SeedContent` (demo: cities, events, documents, rules, guides, clubs, news, KPI values, regions, growth) stays behind `Database:SeedContent`. Demo KPI values are applied only when every KPI still reads 0.
12. **Athlete dedupe.** An application whose email matches an existing non-`Rejected` athlete (ordinal-ignore-case) creates no second row and sends no second mail; the public flow is unchanged (same "received" page). `CrmService.ApplyAsync` returns `(Athlete Athlete, bool Created)`.
13. **Confirmation name via TempData.** `PublicApi` stores the visitor's name under `PublicApi.ConfirmationNameKey` and redirects without `?name=`; `Registered` and `RegisterReceived` read it from TempData (uncached pages).
14. **ICS.** `IcsWriter.Write(events, culture, baseUrl, DateTimeOffset now)`: `DTSTAMP` is `now` (the feed's generation time, as RFC 5545 defines it); timed events get `DTEND;TZID=Asia/Riyadh` = start + `IcsWriter.DefaultDuration` (4 h) on `DateEnd ?? DateStart`; all-day events keep the exclusive date `DTEND`.
15. **Dashboard shell.** `MainLayout` wraps everything in `<MudRTLProvider RightToLeft="@IsRtl">`; IA groups: Overview · Content (Pages, News, Governance, Navigation) · Events (Events, Cities) · Library (Documents, Rules, Training guides) · Statistics · Media · Admin (Users, Settings). Groups render only for the policy that can use them. All labels via `IStringLocalizer<DashboardStrings>`.
16. **Rich text** is Quill 2.0.3 vendored under `wwwroot/lib/quill/` (CSP is `script-src 'self'`; no CDN). `BilingualRichText` binds HTML strings; the server sanitises on save regardless of what the editor emits.
17. **Consolidations.** `AthleteCategories.Arabic` delegates to `EventCategories.Label`; `PublicApi`'s two form handlers share `Api/FormPosts.cs` (`NullIfBlank`, `ToFieldName`, `RoundTrip`); `DashboardAuthTests`/`OperationsEndpointsTests` share `tests/Web/DashboardClient.cs` (`SignInAsync`, `HiddenFields`).
18. **`aria-current`** in `_Header` marks only the nav item with the longest matching href (`events/timeline` beats `events` on `/en/events/timeline`).
19. **Footer year** comes from `TimeProvider` in Riyadh time, not `DateTime.UtcNow`.

```csharp
using System.Text.RegularExpressions;

namespace Triathlon.Web.Domain.Common;

/// <summary>
/// The one slug rule for every slugged aggregate (events, pages, news, guides, rules): lower-case
/// ASCII words joined by single hyphens, at most 128 characters. No dots — a dot makes
/// <c>PublicSite.WantsHtmlStatusPage</c> treat the URL as a static file.
/// </summary>
public static partial class Slugs
{
    public const int MaxLength = 128;

    [GeneratedRegex("^[a-z0-9]+(-[a-z0-9]+)*$", RegexOptions.CultureInvariant)]
    private static partial Regex Pattern();

    public static bool IsValid(string? slug) =>
        !string.IsNullOrEmpty(slug) && slug.Length <= MaxLength && Pattern().IsMatch(slug);
}
```

`Services/ContentGuard.cs`:

```csharp
using Ganss.Xss;
using Microsoft.Extensions.Options;

namespace Triathlon.Web.Services;

/// <summary>
/// The only route editor input takes into storage. HTML is reduced to the allow-list below; file
/// paths must be site-relative under <c>/docs</c> or the configured media prefix. Views keep
/// rendering these fields with <c>Html.Raw</c>, so this class is the whole XSS boundary.
/// </summary>
public sealed class ContentGuard
{
    private const string DocsPrefix = "/docs";

    private static readonly string[] AllowedTags =
    [
        "p", "br", "strong", "em", "b", "i", "u", "s", "ul", "ol", "li", "a", "h2", "h3", "h4",
        "blockquote", "table", "thead", "tbody", "tr", "th", "td", "span", "div", "sup", "sub",
    ];

    private static readonly string[] AllowedAttributes = ["href", "title", "target", "rel", "class"];

    private static readonly string[] AllowedSchemes = ["http", "https", "mailto", "tel"];

    private readonly HtmlSanitizer _sanitizer;
    private readonly string _mediaPrefix;

    public ContentGuard(IOptions<MediaOptions> media)
    {
        ArgumentNullException.ThrowIfNull(media);
        _mediaPrefix = media.Value.NormalizedPublicPrefix;

        _sanitizer = new HtmlSanitizer();
        _sanitizer.AllowedTags.Clear();
        _sanitizer.AllowedTags.UnionWith(AllowedTags);
        _sanitizer.AllowedAttributes.Clear();
        _sanitizer.AllowedAttributes.UnionWith(AllowedAttributes);
        _sanitizer.AllowedSchemes.Clear();
        _sanitizer.AllowedSchemes.UnionWith(AllowedSchemes);
        _sanitizer.AllowedCssProperties.Clear();
        _sanitizer.AllowedAtRules.Clear();
        _sanitizer.AllowDataAttributes = false;
        _sanitizer.KeepChildNodes = true;
    }

    /// <summary>Editor HTML reduced to the allow-list; null when there is nothing left worth storing.</summary>
    public string? Html(string? html)
    {
        if (string.IsNullOrWhiteSpace(html))
        {
            return null;
        }

        var clean = _sanitizer.Sanitize(html).Trim();
        return clean.Length == 0 ? null : clean;
    }

    /// <summary>The path unchanged when it is a site file, null when blank; otherwise a validation error.</summary>
    public string? FilePath(string? path, string field = "FilePath")
    {
        if (string.IsNullOrWhiteSpace(path))
        {
            return null;
        }

        return IsSiteFilePath(path)
            ? path
            : throw new ContentValidationException(field, $"'{path}' is not a file under {DocsPrefix}/ or {_mediaPrefix}/.");
    }

    public bool IsSiteFilePath(string? path)
    {
        if (string.IsNullOrWhiteSpace(path) || path[0] != '/' || path.Contains("//", StringComparison.Ordinal)
            || path.Contains('?', StringComparison.Ordinal) || path.Contains('#', StringComparison.Ordinal)
            || path.Contains('\\', StringComparison.Ordinal) || path.Contains(':', StringComparison.Ordinal))
        {
            return false;
        }

        var underDocs = path.StartsWith(DocsPrefix + "/", StringComparison.Ordinal);
        var underMedia = path.StartsWith(_mediaPrefix + "/", StringComparison.Ordinal);
        if (!underDocs && !underMedia)
        {
            return false;
        }

        var segments = path.Split('/', StringSplitOptions.RemoveEmptyEntries);
        // At least prefix + file name, and no dot-segments anywhere.
        return segments.Length >= 2 && segments.All(s => s != "." && s != "..") && !path.EndsWith('/');
    }
}
```

```csharp
using System.Collections;
using System.Reflection;
using Triathlon.Web.Domain.Common;

namespace Triathlon.Web.Services;

/// <summary>
/// Flattens an aggregate to the fields an editor can change, so the activity log stores a readable
/// before/after diff rather than an object graph with its navigations and stamps.
/// </summary>
public static class Audit
{
    private static readonly HashSet<string> Excluded = new(StringComparer.Ordinal)
    {
        nameof(BaseEntity.Id), nameof(BaseEntity.CreatedAt), nameof(BaseEntity.CreatedBy),
        nameof(BaseEntity.UpdatedAt), nameof(BaseEntity.UpdatedBy), nameof(BaseEntity.DeletedAt),
    };

    public static Dictionary<string, object?> Snapshot(object entity)
    {
        ArgumentNullException.ThrowIfNull(entity);
        var result = new Dictionary<string, object?>(StringComparer.Ordinal);

        foreach (var property in entity.GetType().GetProperties(BindingFlags.Public | BindingFlags.Instance))
        {
            if (!property.CanRead || !property.CanWrite || property.GetIndexParameters().Length > 0 || Excluded.Contains(property.Name))
            {
                continue;
            }

            if (!IsScalar(property.PropertyType))
            {
                continue;
            }

            result[property.Name] = property.GetValue(entity);
        }

        return result;
    }

    private static bool IsScalar(Type type)
    {
        type = Nullable.GetUnderlyingType(type) ?? type;
        if (type == typeof(string)) return true;
        if (typeof(IEnumerable).IsAssignableFrom(type)) return false;
        return type.IsPrimitive || type.IsEnum || type == typeof(decimal) || type == typeof(Guid)
            || type == typeof(DateOnly) || type == typeof(TimeOnly) || type == typeof(DateTimeOffset) || type == typeof(DateTime);
    }
}
```

```csharp
    private void Apply(Page page, PageInput input)
    {
        page.Slug = input.Slug;
        page.TitleEn = input.TitleEn.Trim();
        page.TitleAr = input.TitleAr.Trim();
        page.MetaDescriptionEn = Blank(input.MetaDescriptionEn);
        page.MetaDescriptionAr = Blank(input.MetaDescriptionAr);
        page.IsPublished = input.IsPublished;

        var keep = new HashSet<Guid>();
        foreach (var (blockInput, index) in input.Blocks.Select((b, i) => (b, i)))
        {
            var block = blockInput.Id is { } bid ? page.Blocks.FirstOrDefault(b => b.Id == bid) : null;
            if (block is null)
            {
                block = new PageBlock { PageId = page.Id };
                page.Blocks.Add(block);
            }

            keep.Add(block.Id);
            block.SortOrder = index + 1;
            block.Type = blockInput.Type;
            block.Variant = Blank(blockInput.Variant);
            block.Anchor = Blank(blockInput.Anchor);
            block.EyebrowEn = Blank(blockInput.EyebrowEn);
            block.EyebrowAr = Blank(blockInput.EyebrowAr);
            // The home hero's title is rendered with Html.Raw (it carries <span class="grad"> and <br>).
            block.TitleEn = guard.Html(blockInput.TitleEn);
            block.TitleAr = guard.Html(blockInput.TitleAr);
            block.BodyEn = guard.Html(blockInput.BodyEn);
            block.BodyAr = guard.Html(blockInput.BodyAr);
            block.ItemsJson = BlockItem.Serialize(blockInput.Items.Select(item => item with
            {
                BodyEn = guard.Html(item.BodyEn), BodyAr = guard.Html(item.BodyAr),

    /// <summary>An href an editor typed: a site path, a fragment, mailto/tel, or an absolute http(s) URL. Anything else is dropped.</summary>
    internal static string? SafeHref(string? href)
    {
        var value = Blank(href);
        if (value is null) return null;
        if (value.StartsWith('#') || value.StartsWith("mailto:", StringComparison.OrdinalIgnoreCase) || value.StartsWith("tel:", StringComparison.OrdinalIgnoreCase)) return value;
        if (value.Contains(':', StringComparison.Ordinal))
            return Uri.TryCreate(value, UriKind.Absolute, out var uri) && (uri.Scheme == Uri.UriSchemeHttp || uri.Scheme == Uri.UriSchemeHttps) ? value : null;
        return value.Contains("//", StringComparison.Ordinal) ? null : value.TrimStart('/');
    }

    private static string? Blank(string? value) => string.IsNullOrWhiteSpace(value) ? null : value.Trim();
```

```csharp
/// <summary>ADR 0001: restoring a parent restores the children its delete cascaded — the ones whose DeletedAt fell in the same second.</summary>
public static class Restore
{
    public static void Aggregate<TChild>(BaseEntity parent, IEnumerable<TChild> children) where TChild : BaseEntity
    {
        ArgumentNullException.ThrowIfNull(parent);
        ArgumentNullException.ThrowIfNull(children);
        var deletedAt = parent.DeletedAt ?? throw new InvalidOperationException("The parent is not deleted.");
        parent.DeletedAt = null;
        foreach (var child in children)
        {
            if (child.DeletedAt is { } at && Math.Abs((at - deletedAt).TotalSeconds) < 1)
            {
                child.DeletedAt = null;
            }
        }
    }
```
